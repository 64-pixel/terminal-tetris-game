# terminal-tetris-game
This is terminal tetris. I created this, because i wanted to feel a bit nostalgic. So i created a bit modern tetris not like the old school one or the colorfull ones. It is similiar but not the same. You have basic functions such as moving from left to right, speeding up the fall and rotating. You also have modern version of tetris music playing in the background, which you can turn off/on, increase/decrease the volume. And sounds when you move, rotate and when the end screen is shown. 

How to play:
In my releases you have an exe file, which you download and run. Your antivirus might show that it is dangerous, which windows did show me when i downloaded my own file. But you have to trust me it is not a virus.
